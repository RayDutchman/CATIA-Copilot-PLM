## 执行说明

- **测试入口**：全部在 `http://localhost:8000`（FastAPI 后端）。行为可疑时 agent 会去 :8005（Payara）对拍，你无需自己对拍。
- **账号**：
  | 账号 | 密码 | 角色 |
  |------|------|------|
  | test1 | password | GD50 工作区管理员（主测试账号） |
  | alice | password | 普通用户（权限测试用） |
  | admin | password | 平台全局管理员 |
  | bob | password | T1 中新注册（权限测试用） |
- **双工作区**：`TESTR7`（T0 新建，走完整创建链路+空态）为主战场；`GD50`（种子数据）仅用于标注 `[GD50]` 的步骤。
- **优先级**：`[P1]` 必测（约 70 步）；`[P2]` 有时间再测。建议先通刷全部 P1，再回头补 P2。
- **遇到异常**：记录后**继续往下测**，不要停（除非后续步骤被阻塞）。同一异常影响多步时只记一次。
- **结果标记**：每步前的 `[ ]` 打勾表示通过；异常的步骤在编号后写异常摘要。
