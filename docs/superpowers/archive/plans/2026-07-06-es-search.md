### Task 2: `indexer_manager.py` — ES 连接 + 索引管理 + 文档 CRUD

**读取 Java**: `IndexerManagerBean.java` 全部 + `IndexerMapping.java` 全部 + `EntityMapper.java` 全部

**实施**:
- 创建 `app/services/indexer_manager.py`
- 实现 `IndexerManager` 类（单例 `indexer_manager`）:

| 方法 | 对标 Java | 说明 |
|------|----------|------|
| `__init__` + `es` property | `@Inject JestClient` | 惰性连接，`Elasticsearch([settings.ES_URL])` |
| `_part_index(ws)` | `indicesUtils.getIndexName(ws, INDEX_PARTS)` | 返回 `"docdoku-plm-{ws}-parts"` |
| `_doc_index(ws)` | `indicesUtils.getIndexName(ws, INDEX_DOCUMENTS)` | 返回 `"docdoku-plm-{ws}-documents"` |
| `create_index(ws)` | `createWorkspaceIndex` | exists → create，index=parts+documents，mapping body 按 IndexerMapping 常量 |
| `delete_index(ws)` | `deleteWorkspaceIndex` | exists → delete，ignore 404 |
| `_part_iteration_to_doc(pi)` | `EntityMapper.partIterationToJSON` | PartIteration → ES doc dict（字段名用 IndexerMapping 常量值） |
| `_doc_iteration_to_doc(di)` | `EntityMapper.documentIterationToJSON` | DocumentIteration → ES doc dict |
| `index_part_iteration(pi)` | `indexPartIteration` | `es.index(index, id="{number}-{version}-{iteration}", body=doc)` |
| `index_part_revision(pr)` | — | 便捷封装: `for pi in pr.iterations: index_part_iteration(pi)` |
| `index_document_iteration(di)` | `indexDocumentIteration` | 同上，id=`"{docMasterId}-{version}-{iteration}"` |
| `index_document_revision(dr)` | — | 便捷封装: `for di in dr.iterations: index_document_iteration(di)` |
| `delete_part_revision(pr)` | `removePartIterationFromIndex` | 遍历 `pr.iterations` → `es.delete(index, id="{number}-{version}-{iteration}", ignore=[404])` |
| `delete_document_revision(dr)` | `removeDocumentIterationFromIndex` | 同上 |
| `reindex_all(db, ws)` | `doIndexWorkspaceData` | delete_index → create_index → 分页 (BULK_SIZE=50) → `helpers.bulk` → return `{"parts": N, "documents": M, "errors": [...]}` |

- **必须按 iteration 索引**：一个 iteration = 一个 ES doc，doc ID 含 iteration 号。EntityMapper 所有字段从 iteration 取，按 revision 索引会丢失 iterationNote/modificationDate 等字段。
- **必须对照映射文档 §2.3 核实 ORM 字段！** 尤其注意 `di.documentmaster_id` 而非 `di.doc_master_id`，`pi.partrevision_version` 等。
- [ ] 方法级冒烟: 用假对象验证 `_part_iteration_to_doc` + `index_part_iteration` 不抛 AttributeError
- [ ] 验证 doc ID 含 iteration 号: `{number}-{version}-{iteration}` 格式
- [ ] Commit: `feat: ES搜索——indexer_manager.py（迭代级索引+文档CRUD+BULK_SIZE=50 reindex）`

### Task 2b: `notifier.py` — reindex 邮件通知

**读取 Java**: `IndexerManagerBean.java` 中 `doIndexWorkspaceData`（行 355-420） + `sendBulkIndexationSuccess`/`sendBulkIndexationFailure` 调用

**实施**:
- 创建 `app/services/notifier.py`，实现 `send_reindex_notification(to_email, locale, ws, result)`:
  - `result = {"parts": N, "documents": M, "errors": [...]}`
  - errors 为空 → i18n 成功邮件正文
  - errors 非空 → i18n 失败邮件正文（含 errorMessages 列表）
  - SMTP 连接: `smtplib.SMTP("smtp", 1025)`（MailHog 容器，端口 1025）
  - 发送失败 → log warning，不 raise
- i18n: 邮件正文模板支持中英双语（先做 zh + en，后续扩展），用户 locale 从 `Account.language` 字段取（查看 `app/models/account.py`）
- 在 `indexer_manager.reindex_all` 中集成: errors 收集完后调 `notifier.send_reindex_notification(user_email, locale, ws, result)`
- 验证: 调 reindex endpoint → 打开 `http://localhost:8003`（MailHog Web UI）确认收到邮件
- [ ] Commit: `feat: ES搜索——notifier.py reindex邮件通知（smtplib+MailHog+i18n）`
